# Wager Royale

This workspace contains the Wager Royale frontend (React) for Clash Royale wagering and matchmaking.

Key updates:
- Skill-based matchmaking by crowns (trophies) with UI filters.
- Mandatory Clash Royale account verification before matchmaking or wagers.
- Free 7-day trial starting at registration/first link; $13/month subscription thereafter.

See wager_royale_frontend/README.md for detailed implementation plan, env variables, and integration notes.
