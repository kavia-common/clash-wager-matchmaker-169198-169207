# Wager Royale

This workspace contains the Wager Royale frontend (React) for Clash Royale wagering and matchmaking.

Highlights:
- Ocean Professional theme with modern, minimalist UI.
- Skill-based matchmaking by crowns (trophies) with URL-persisted filters.
- Mandatory Clash Royale account verification before matchmaking/wagers.
- Free 7-day trial and $13/month subscription gating and flows.
- Payment scaffolding with hosted checkout placeholders.
- Route protection with redirects to link/subscription pages.

See wager_royale_frontend/README.md for full details, environment variables, and integration notes.
